## 网络限制与解决方案

### 问题1: 国内服务器无法访问 Claude

**解决方案**:
- 在德国本地与 Claude 交互
- 将代码/脚本修改后通过 git 同步到服务器
- 服务器只执行，不做交互式开发

### 问题2: 国内下载国外资源慢

**表现**:
- CARLA 下载 (8GB) 需要 2-3 小时
- GitHub clone 有时较慢

**解决方案**:
- 使用 `screen` 后台下载，避免 SSH 断开
- 使用 `wget -c` 支持断点续传
- AutoDL 学术加速: `source /etc/network_turbo` (部分地区不可用)

### 问题3: GPU 空闲自动关机

**表现**:
- AutoDL 检测到 GPU 无使用会自动关机
- 导致下载/克隆中断

**解决方案**:
- 使用 screen 保持会话
- 后台运行简单 GPU 任务:
  ```bash
  python3 -c "import torch; x=torch.zeros(1).cuda(); import time; time.sleep(99999)" &
  ```

## 工作流程

### 开发流程 (德国端)

1. 与 Claude 讨论方案
2. Claude 生成/修改代码和脚本
3. 本地 git commit & push

### 实验流程 (中国端)

1. `git pull` 获取最新代码
2. 按顺序执行 `scripts/` 下的脚本
3. 保存输出/结果
4. 如有问题，复制输出发回德国分析

### 结果同步流程

1. 服务器上将结果文件 git add/commit/push
2. 德国端 git pull 查看结果
3. 与 Claude 分析结果

---

## 注意事项

1. **永远不要假设 Claude 可以直接在服务器执行命令** - 所有服务器操作必须通过脚本
2. **长时间任务用 screen** - 避免 SSH 断开或自动关机
3. **大文件放数据盘** - `/root/autodl-tmp`
4. **保持 GPU 活动** - 防止自动关机
5. **脚本要幂等** - 可以重复执行不出错
